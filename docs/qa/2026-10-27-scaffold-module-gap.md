# 脚手架模块差距分析（PmStudio vs 品茗 2027 V6.0）

日期：2026-10-27  
范围：只读分析；未启动或操作 Pmsg，未修改品茗安装目录，未修改业务源码。

## 结论

| 指标 | 数量 |
| --- | ---: |
| PmStudio 当前注册脚手架模块 | 10 |
| 品茗统一脚手架能力（去重后） | 81 |
| 已覆盖 | 4 |
| 部分覆盖 | 9 |
| 未覆盖 | 68 |

这里的“覆盖”只表示 PmStudio 已有相同主计算对象和可运行的校核链路，**不表示公式已经验证**。PmStudio 注册表中的 10 个模块全部为 `verified=false`；`scaffold-fastener-pinming` 虽带有一份导出计算书逐项一致记录，但模块总体仍明确保持 `verified=false`。

统计边界：

- 10 个 `SchemeConfig.ini` 共出现 198 次直接模板映射。
- 按“编码=模板名”去重后得到 110 个全局唯一的编码/模板名对、84 个编码、35 个模板配置名。
- 模板编码会跨地区复用且同码异义，不能把 198 次映射或 110 个编码/模板对称为 198/110 个独立计算模块。
- 81 个能力由 `SchemeConfig.ini` 中的模块声明、`[ConfigFileModuleInfo]` 分组以及帮助手册脚手架章节目录合并得到；仅做名称别名、全半角、重复模板和同一对象的地区拼写归并。

地区/规范差异：

1. `SchemeConfig.ini` 只记录能力/模板映射，不记录完整计算公式或标准条款；规范差异由地区条目和帮助手册所列规范体系共同确认。
2. 全国、江苏、上海主要使用相似的 10xx 编码体系；北京、重庆、福建是盘扣和花篮螺栓子集；浙江、山东、广东、湖北使用当地结构形式和/或独立编码段。
3. 山东 `1014/1015/1017` 与全国 `附着升降/悬挂吊篮/三角形外挂架` 同码异义；广东 `46xx`、湖北 `45xx` 不宜强行映射到 10xx。
4. PmStudio 门式模块登记主标准为 JGJ 128-2010，而帮助手册门式章明确引用 JGJ/T 128-2019；这是规范性版本差距，不能仅凭“门式”同名认定完全一致。
5. PmStudio 目前每个模块只登记一个主标准；品茗同章会并列提供 JGJ 130-2011、T/CECS 699-2020、GB 51210-2016、JGJ/T 231-2021 及地方版本选择。

## 三、品茗帮助手册脚手架章目录核对

帮助手册“全国模块 / 第一章 脚手架工程”下有 7 节：

| 节 | 手册中的独立条目 |

| 悬挑式脚手架 | 三角形钢管悬挑；型钢悬挑（扣件/碗扣/门式/盘扣）；阳角 B；多排悬挑主梁；搁置主梁 |
| 花篮螺栓悬挑架 | 扣件/碗扣/盘扣/门式；阳角 B；多排主梁；搁置主梁 |
| 工具式脚手架 | 附着升降；导轨式附着升降（正在优化为全钢爬架）；悬挂式吊篮；三角形外挂架 |
| 现场施工平台 | 盘扣式操作/卸料；钢管落地卸料；型钢悬挑卸料；满堂脚手架/支撑架；扣件/盘扣/门式移动平台；临边防护栏杆；井道操作平台 |

核对结果：

- 帮助手册明确存在、但 10 个 `SchemeConfig.ini` 没有给出完整直接映射的能力：`盘扣式操作平台`、`盘扣式卸料平台`、`临边防护栏杆`、`井道操作平台`。
- `连墙件计算 1035` 只出现在江苏、全国、上海配置的功能声明中，没有作为直接编码映射写入。
- `脚手架架在楼板上 1025` 在若干地区通过 `[ConfigFileModuleInfo]` 分组出现，不一定是直接赋值行。
- 帮助手册更新页提到“盘扣式脚手架搭设防护棚”和“电梯井道搭设盘扣式操作平台”，但当前配置不能唯一证明其模板编码；本次分别归入 `防护棚` 与 `井道操作平台` 家族，不额外虚增能力数。
- 全国配置中的 `1091`、`1092`、`1093`、`1094` 只有映射、无同名声明；不凭猜测命名，列入待确认项。
- 全国配置中 `1097` 的声明名为“爬架临时支撑平台(型钢悬挑)”，却被映射到“爬架临时支撑平台(扣件式)”配置文件，存在声明/配置名不一致。

## 七、仅地区差异、重复模板与编码冲突

1. 同一能力跨地区重复声明很常见。例如扣件式 1001 在江苏/全国/上海重复出现；这些不是 3 个独立计算能力。
2. `1011` 在全国写作“多排悬挑架主梁验算”，江苏/上海写作“多排悬挑架主梁验算(无联梁)”，按同一主对象归并。
3. `花篮螺栓多排悬挑架(无联梁)` 与 `多排悬挑架主梁验算(花篮螺栓式)` 是同一地区不同拼写，归并；有联梁同理。
4. `上拉型钢悬挑架` 与 `上拉式悬挑承力架` 按同一地区结构体系归并。
5. 广东 `多排悬挑架(无/有纵向钢梁)` 与全国 `多排悬挑架主梁验算(无/有联梁)` 按语义归并。
6. `施工升降机卸料平台` 与 `施工升降机卸料平台(扣件式)` 归并；`施工升降机卸料平台(盘扣式)` 与帮助手册“盘扣式卸料平台”归并。
7. 福建“型钢悬挑脚手架架(盘扣式)”是错字/重复“架”，归并到“型钢悬挑脚手架(盘扣式)”；全角右括号仅做格式归并。
8. `悬挂式吊篮`（1015）与“标准吊篮”（1069）按通用吊篮主对象归并；8 种悬挂构造仍保留为更细能力条目。
9. 1080 在全国表示“三角形外挂架”，在浙江表示“拉杆式悬挑脚手架(门式)”；不能仅按数字合并。
10. 1079 在江苏表示“挑梁式悬挑承力架(盘扣式)”，在浙江表示“拉杆式悬挑脚手架(阳角整体计算)”，在全国/江苏盘扣配置中又作为未声明映射出现；必须按地区解释。
11. 1014/1015/1017、1010-1013 在山东与全国/江苏/上海存在同码异义，跨地区不能按编码直接合并。

## 八、建议实现优先级

优先级依据：全国/上海/江苏出现频次、帮助手册是否有独立章节、与当前 9 个模块的结构距离。

### P0：先补齐高频主链路

1. 把 `cantilever-scaffold` 从“型钢悬挑梁验算”扩成“型钢悬挑脚手架(扣件式)”：接入上部扣件架立杆轴力、连墙件、风荷载、梁板局部受压与锚固共同工作。
2. 新增盘扣式落地脚手架；这是北京、福建、江苏、全国、上海均出现且帮助手册完整成章、当前完全没有的常用体系。
3. 将 `ground-operation-platform` 拆出或参数化为钢管落地卸料平台、盘扣式操作/卸料平台、施工升降机卸料平台，补齐平台专项荷载和构造。
4. 新增扣件式移动操作平台：与现有落地平台最近，主要增量是脚轮防滑移、1.5 kN/m² 限值、工作/非工作水平荷载与支撑脚抗倾覆。
5. 新增脚手架架在楼板上模块，补齐当前结构支座边界；公共连墙件计算已由 `scaffold-tie-member` 落地。
6. 升级门式模块的规范版本与条文映射，使 JGJ 128-2010 内容与手册引用的 JGJ/T 128-2019 分离清楚。
7. 完成 `cantilever-operation-platform` 的平行/垂直外墙主梁两类构造，达到品茗型钢悬挑卸料平台完整能力。

### P1：补全国和主流地区常用体系

1. 满堂支撑架、多排扣件脚手架、型钢悬挑门式/碗扣/盘扣、多排悬挑主梁有/无联梁、搁置主梁。
2. 花篮螺栓悬挑架扣件/碗扣/盘扣/门式及其阳角、多排、搁置主梁分支。
3. 防护棚、斜道、悬挑防护棚、型钢悬挑防护棚。
4. 上拉式和拉杆式悬挑体系；两者已有明确地区需求，但应先抽象共享“上拉杆件-主梁-锚固-抗倾覆”内核。
5. 井道操作平台与临边防护栏杆；与现有平台/构造校核距离较近，且帮助手册有独立模型。

### P2：低频、地方专用或结构差异较大

1. 挑梁式、侧埋式等地方专用悬挑体系。
2. 双排外竹脚手架、木脚手架、三角形钢管悬挑脚手架、三角形外挂架。
3. 7 种非标吊篮悬挂构造与女儿墙卡钳专项模型。
4. 爬架临时支撑平台扣件/盘扣/型钢悬挑。
5. 无明确模板编码的新增条目，需先向厂商/实际界面确认编码和输入输出，再进入研发队列。
