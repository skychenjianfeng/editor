# 独立连墙件计算模块设计

日期：2026-10-27
状态：已批准实施

## 目标

新增独立脚手架公共模块 `scaffold-tie-member`，复刻品茗帮助手册中的“连墙件计算”入口。模块在不改变现有扣件式脚手架结果的前提下，独立完成连墙件风荷载轴力、强度和稳定性、连接承载力、扣件抗滑及布置构造校核，并接入参数页、四视图、DXF/PNG、DOCX 计算书和批量回归。

计算基准为 JGJ 130-2011，同时应用 GB 55023-2022 的强制构造要求及 GB 50009-2012 的风压高度变化系数。首版不切换 CECS 699-2020 计算口径，因为其式 5.2.13 风荷载分项系数为 1.5，而 JGJ 130-2011 式 5.2.13 为 1.4；不得在同一结果中混用两套系数。

## 不在本次范围

- 不修改 `scaffold-fastener` 或 `scaffold-fastener-pinming` 的输入、公式或结果。
- 不实现 CECS 699-2020 双口径切换。
- 不对连接节点、预埋件、焊缝、螺栓群或建筑结构本体作完整构件设计；连接承载力 `Nv` 仍按用户提供的可复核设计值验算。
- 不把自算结果声明为已经通过品茗 oracle。模块保持 `verified=false`，直到取得同参数品茗“连墙件计算”RTF 并逐项对算。

## 模块契约

- key：`scaffold-tie-member`
- title：`连墙件计算`
- category：`落地与满堂`
- standard：`JGJ 130-2011`
- verified：`false`
- report：`report.build_generic_docx`
- geometry：通过 `drawing.build_geometry_for_module` 分派到专用连墙件几何。

`param_spec()` 返回三组参数：

### 基本参数

- `layout`：单排 / 双排，默认双排
- `scaffoldType`：双排落地 / 双排悬挑 / 单排，默认双排落地
- `H`：架体高度，m
- `h`：步距，m
- `la`：立杆纵距，m
- `lb`：立杆横距，m
- `tieLength`：连墙件计算长度，m
- `steel`：φ48×2.8 / φ48×3.0 / φ51×3.0

### 连墙件与构造

- `tieVerticalSpacing`：连墙件竖向间距，m
- `tieHorizontalSpacing`：连墙件水平间距，m
- `connectionType`：扣件连接 / 焊缝连接 / 螺栓连接 / 膨胀螺栓连接 / 软拉硬撑
- `tieNv`：连接受拉或受压承载力设计值，kN
- `tieNetArea`：净截面面积，mm²；0 表示按毛截面取值并列入计算说明
- `tieOffset`：偏离主节点距离，mm
- `tieFromFirstStep`：是否从底层第一步纵向水平杆设置
- `tieArrangement`：菱形 / 方形 / 矩形，仅作方案记录

### 风荷载

- `wind`：基本风压 `w0`，kN/m²
- `terrain`：A / B / C / D
- `enclosure`：全封闭 / 半封闭 / 敞开
- `backdrop`：全封闭墙 / 敞开、框架和开洞墙
- `phiWind`：挡风系数

`H` 同时作为连墙件风荷载计算高度，因为连墙件轴力按架体顶部最不利位置取值。

## 计算语义

复用现有 `scaffold_fastener` 的钢管截面、稳定系数与风系数计算能力时，应只调用其稳定、可测试的计算函数；不复制一份会漂移的公式表。允许在新增模块内实现轻量包装，但不得改变现有模块公开的 `run({})` 结果。

### 基本派生量

- 钢管毛截面面积 `A`、惯性矩 `I`、回转半径 `i`，与现有扣件式截面定义一致。
- 连墙点覆盖面积 `Aw = tieVerticalSpacing × tieHorizontalSpacing`。
- 等效竖向步数 `tieSteps = tieVerticalSpacing / h`。
- 等效水平跨数 `tieBays = tieHorizontalSpacing / la`。
- `wk = μz(H) × μs × w0`，其中 `μs` 按现有封闭状况、背靠建筑和挡风系数规则计算。

### JGJ 130-2011 轴力

- `Nlw = 1.4 × wk × Aw`（式 5.2.13）
- `N0 = 2.0kN`（单排）或 `3.0kN`（双排）
- `Nl = Nlw + N0`（式 5.2.12-3）

### 强度、稳定与连接

- 强度：`Nl / Ac ≤ 0.85f`（式 5.2.12-1），`f=205N/mm²`
- 稳定：`Nl / (φA) ≤ 0.85f`（式 5.2.12-2）
- `λ = tieLength × 1000 / i`
- `φ` 按 JGJ 130-2011 附录 A 表 A.0.6 取值；该表有效范围为 `λ=0～250`（正文第 71～72 页），超出上限必须报错，不得用端点值代替
- 连接：`Nl ≤ Nv`（式 5.2.14）
- 扣件抗滑：仅当 `connectionType=扣件连接` 时输出，`Nl ≤ Rc=8.0kN`（式 5.2.15）

### 布置与构造

- 竖向间距一般不得超过 3 步；双排悬挑且 `H>50m` 时不得超过 2 步（JGJ 130-2011 表 6.4.2，正文第 39 页）。
- 水平间距不得超过 3 跨。
- 双排落地及单排的覆盖面积不得超过 40m²；双排悬挑且所在高度大于 50m 时不得超过 27m²（表 6.4.2）。
- 单排架体高度不得超过 24m。
- 连墙件偏离主节点不得超过 300mm（第 6.4.3 条）。
- 必须从底层第一步纵向水平杆处设置；无法设置时应另填可靠措施，本模块对“否”直接判不满足（第 6.4.3 条）。
- 连墙点之上不应新增无约束悬臂工况；模块要求连墙件为刚性构造（GB 55023-2022 第 4.4.6 条）。
- 高度超过 24m 时，`软拉硬撑` 直接判不满足；即使不超过 24m，也输出“刚性构造优先”的计算说明。

结果行使用现有通用契约：`no/key/item/value/limit/unit/ratio/ok/clause/control/detail`。对于“不得超过”和“不得小于”两类条件，必须显式设置 `ok`，不得只依赖 `value <= limit` 的默认方向。

## 验证与错误处理

- 所有长度、间距、高度、承载力、风压和截面参数必须为正数或合法非负值。
- `tieNetArea=0` 时采用钢管毛截面；`tieNetArea>0` 时必须不大于该钢管毛截面 `A`，否则抛出 `ValueError`。
- 连墙件长细比 `λ>250` 时超出附录 A 表 A.0.6 范围，必须抛出包含 `250` 的 `ValueError`，不得截断到表端点。
- 未知钢管、单双排、架体类型、连接方式、地面粗糙度、封闭状况或背靠建筑类型应抛出明确 `ValueError`。
- `tieNetArea=0` 时使用毛截面，但 payload assumptions 必须说明按毛截面计算、后续应以实际净截面复核。
- `connectionType` 不是扣件连接时，不生成扣件抗滑结果行；报告不得把它误写成已通过。
- `summary` 必须按实际结果行重新统计，不能保留陈旧计数。

## 出图与计算书

新增 `drawing_tie_member.py`，提供 `elevation / plan / side / section` 四个视图：

- 正立面显示建筑墙面、内外立杆、连墙件位置和竖向间距。
- 平面显示墙体、两排立杆、连墙件水平间距和外伸长度。
- 侧立面/剖面显示墙体、连墙件、内外立杆及计算长度。
- 图形明确标注“参数化示意（非施工图）”，不冒充专项施工图。

`scaffold_report_figures.py` 为 `scaffold-tie-member` 生成正立面和平面两张 PNG。通用 DOCX 参数表应使用用户可读中文标签；新增字段进入统一参数标签映射。计算书包含规范依据、参数、两张图、逐项计算过程、结果表和结论。

## 测试与验收

实施必须按 TDD 先写失败测试，再写生产代码。

### RED/GREEN 单元覆盖

1. 模块注册、param spec、默认 `run({})` 和 `verified=false`。
2. 默认双排结果数值：`N0=3kN`、`Nlw=1.4×wk×Aw`、`Nl=Nlw+N0`，连续量按容差校验。
3. 基本风压、挡风系数或连墙件覆盖面积增加时，`Nlw/Nl` 单调增加。
4. 净截面面积减小时，强度应力增加。
5. 连墙件计算长度增加时，稳定应力增加。
6. 一般工况竖向超过 3 步、双排悬挑 `H>50m` 超过 2 步、水平超过 3 跨、覆盖面积超限、偏移超过 300mm、首步未设置时分别失败。
7. 单排高度超过 24m、高度超过 24m 使用软拉硬撑时失败。
8. 双排悬挑高架覆盖面积超过 27m² 时失败。
9. 非扣件连接不输出 `tie_coupler_slip`；扣件连接输出并按 8.0kN 校核。
10. 非法枚举、非正尺寸和负承载力抛出 `ValueError`。
11. `λ>250` 和 `tieNetArea>A` 抛出 `ValueError`；`λ≤250`、`tieNetArea=0` 或 `tieNetArea≤A` 合法。

## 交付边界

- 新增模块首版即 `verified=false`；未取得品茗连墙件 RTF 前不得进入 verified 列表。
- 本模块不会改变现有 9 个模块的任何 result 数量或默认数值。
- 如果 HTTP 服务未运行，仍须通过 Django/registry 级别的等价集成测试；不得把单元测试等同于真实 API 验收。
