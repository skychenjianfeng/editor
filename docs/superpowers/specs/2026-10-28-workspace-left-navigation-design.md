# 玄构天枢工作台左侧目录设计

日期：2026-10-28

状态：方向已确认，等待设计文档复核

## 目标

给项目工作台增加稳定的左侧目录，让“工作台、项目管理、系统设置、回收站”成为清晰的一级入口，同时保持当前项目表格、指标、筛选和新增项目的既有能力。

## 范围

本次实现：

- 桌面端左侧固定目录。
- 移动端目录按钮与抽屉。
- 工作台总览。
- 项目管理页面。
- 系统设置信息页。
- 回收站空态页。
- 四个入口的路由、选中态和键盘可访问性。

本次不实现：

- 项目软删除、恢复和彻底删除。
- 系统设置的持久化编辑。
- 用户、团队、权限和地区计算规则切换。
- 回收站数据接口。

## 路由与信息架构

| 目录项 | 路由 | 内容 |
| --- | --- | --- |
| 工作台 | `/workspace` | 四项指标、快速新建和最近项目 |
| 项目管理 | `/workspace/projects` | 完整项目搜索、状态筛选、项目 CRUD |
| 系统设置 | `/workspace/settings` | 当前账号、品牌、数据边界与会话说明 |
| 回收站 | `/workspace/recycle-bin` | 未启用软删除的说明和空态 |

`/projects/:projectId/calc` 保持现状，从工作台或项目表格进入。

## 组件结构

- Create `WorkspaceLayout.tsx`
  - 负责共享 `WorkspaceHeader`、桌面目录、移动目录和 `<Outlet />`。
- Create `WorkspaceSidebar.tsx`
  - 负责四个 `NavLink`、分组标题、图标和选中态。
- Create `WorkspaceMobileDirectory.tsx`
  - 使用现有 shadcn Dialog 构建左侧抽屉；路由变化后关闭。
- Refactor `WorkspacePage.tsx`
  - 作为工作台总览，不再直接渲染页头。
  - 保留四项指标、搜索、状态筛选与项目表，项目表限制为最近项目视图。
- Create `ProjectManagementPage.tsx`
  - 复用现有 `ProjectTable`、`ProjectFormDialog` 和项目 API。
  - 提供完整项目搜索、状态筛选、新增、编辑、删除和进入计算。
- Create `SystemSettingsPage.tsx`
  - 只读展示当前账号、品牌、地区规则边界和本地会话说明。
- Create `RecycleBinPage.tsx`
  - 明确说明当前删除为直接删除，回收站尚未启用。
- Modify `WorkspaceHeader.tsx`
  - 增加移动端目录按钮；桌面端保持品牌与用户菜单。
- Modify `App.tsx`
  - 增加 `/workspace` 嵌套路由。

## 桌面布局

- 顶部深色 `WorkspaceHeader` 横跨全宽并保持 sticky。
- 主区域从 Header 下方开始，为两列：
  - 左侧目录宽 232px，桌面端 sticky，占满可用高度。
  - 右侧内容最小宽度为 0，独立滚动，防止项目表撑破页面。
- 目录顶部显示“工作台目录”，与页头品牌形成上下文。
- 目录分组：
  - 总览：工作台、项目管理。
  - 系统：系统设置、回收站。
- 当前路由使用深墨绿背景、白色文字和 `aria-current="page"`。
- 非选中项使用中性灰，悬停显示浅灰背景。

图标：

- 工作台：`LayoutDashboard`
- 项目管理：`FolderKanban`
- 系统设置：`Settings`
- 回收站：`Trash2`

全部使用 Lucide。

## 移动布局

- `WorkspaceHeader` 左侧增加菜单按钮，带“打开工作台目录”可访问名称。
- 点击后打开左侧抽屉，覆盖在主内容上方，带遮罩。
- 抽屉复用同一 `WorkspaceSidebar`。
- 点击任何目录项、遮罩或 Escape 都关闭抽屉。
- 路由变化后自动关闭抽屉。
- 390px 下目录不常驻，主内容不产生横向溢出。

## 页面内容

### 工作台

- 保留四项指标：全部项目、计算中、计算方案、已完成。
- 保留搜索和状态筛选。
- 项目表显示最近项目；最多显示 8 行。
- 提供“查看全部项目”链接到 `/workspace/projects`。
- 提供“新建项目”主操作。

### 项目管理

- 保留当前搜索、状态筛选、刷新和项目表。
- 新建项目、编辑项目、删除项目、进入计算行为不变。
- 页面标题为“项目管理”，说明区强调项目台账而非总览指标。

### 系统设置

只读展示：

- 当前账号邮箱和显示名称。
- 产品品牌“玄构天枢”。
- 数据归属说明：项目、方案、计算记录按当前账号隔离。
- 地区规则边界：地区只作为项目属性，不切换当前计算规范。
- 会话说明：Session Cookie + CSRF，退出后需重新登录。

不放置无效的开关或可编辑输入框。

### 回收站

- 标题“回收站”。
- 空态图标和文案。
- 明确说明：当前项目删除仍是直接删除，回收站功能尚未启用。
- 提供“返回项目管理”按钮。

## 状态与数据

- 项目数据继续使用 TanStack Query，不复制到 Zustand。
- 目录选中态完全由路由决定。
- 移动抽屉开关属于局部 UI 状态，放在 `WorkspaceLayout`。
- 不新增后端模型、迁移或接口。

## 错误与可访问性

- 目录使用 `nav`、列表结构和 `NavLink`。
- 当前项带 `aria-current="page"`。
- 移动菜单按钮有可访问名称和展开状态。
- 抽屉使用 Dialog 标题、焦点约束和 Escape 关闭。
- 动画使用 `motion/react`，并尊重 reduced motion。
- 项目表、错误态、删除二次确认沿用现有组件。

## 回滚

- 新增页面和目录组件可独立回滚。
- 删除新增嵌套路由即可恢复单页工作台。
- 不涉及数据库或计算内核，回滚不丢失项目数据。
